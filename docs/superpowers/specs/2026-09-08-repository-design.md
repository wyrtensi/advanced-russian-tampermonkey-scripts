# Advanced Russian Tampermonkey Scripts — дизайн репозитория

## Цель

Создать публичный GitHub-репозиторий `wyrtensi/advanced-russian-tampermonkey-scripts`, из которого начинающий пользователь сможет установить каждый userscript одним нажатием, понять требуемые настройки браузера и увидеть результат работы до установки. Структура должна позволять добавлять новые независимые скрипты без переработки существующих.

## Состав первой версии

Репозиторий публикует три независимых userscript:

1. `Marketplace Cross Search` — выбор одного или нескольких маркетплейсов прямо в поисковой строке Ozon, Wildberries, Яндекс Маркета, Авито и AliExpress.
2. `Google → Yandex Search Button` — кнопки перехода из Google в Яндекс и поиска по маркетплейсам.
3. `Yandex → Google Search Button` — кнопки перехода из Яндекса в Google и поиска по маркетплейсам.

Существующая логика скриптов переносится без функциональной переработки. Допустимы только изменения метаданных, необходимые для публикации и автоматических обновлений.

## Установка и обновления

Каждый файл заканчивается на `.user.js`. Прямая ссылка на raw-версию файла в ветке `main` должна открывать стандартное окно установки Tampermonkey.

В заголовок каждого userscript добавляются:

- `@homepageURL` и `@supportURL`, ведущие на репозиторий;
- `@downloadURL` и `@updateURL`, ведущие на raw-файл соответствующего скрипта;
- русское описание назначения скрипта;
- уникальный namespace репозитория.

Версии существующих скриптов повышаются на один patch-релиз из-за изменения канала распространения. Пользователь устанавливает только нужные ему возможности; общего сборочного скрипта нет.

## README

README написан на русском языке и ориентирован на человека без технического опыта. В начале размещаются название, короткое объяснение коллекции и предупреждение, что скрипты работают только вместе с менеджером userscript.

Для каждого скрипта показываются:

- название и простое описание;
- поддерживаемые сайты;
- скриншот реальной страницы с активным скриптом;
- заметная ссылка `Установить` на raw-файл;
- короткая инструкция по использованию.

Отдельная пошаговая секция объясняет:

1. как установить Tampermonkey из официального магазина расширений Chrome или Edge;
2. как открыть страницу управления расширениями;
3. как включить режим разработчика и разрешение пользовательских скриптов, если браузер этого требует;
4. как перейти по кнопке установки и подтвердить действие в Tampermonkey;
5. как проверить, что скрипт включён;
6. как обновить или удалить скрипт;
7. что делать, если кнопки не появились.

README также содержит раздел для будущих дополнений и MIT-лицензию проекта.

## Скриншоты

Скриншоты снимаются с живых страниц через браузер с установленными локальными версиями userscript. В кадре должен быть хорошо виден добавленный интерфейс, но не должны попадать персональные данные, история, профиль или другие приватные элементы.

Для `Marketplace Cross Search` меню выбора площадок показывается раскрытым. Для двух переключателей поиска в кадре должны быть видны добавленные кнопки рядом со строкой поиска. Изображения сохраняются в PNG и отображаются непосредственно в README.

Если конкретный сайт блокирует автоматизированный браузер или не загружается, работа останавливается и проблема сообщается пользователю; подмена живого скриншота нарисованным макетом без отдельного согласования запрещена.

## Проверка качества

Перед публикацией выполняются:

- синтаксическая проверка всех `.user.js`;
- проверка обязательных метаданных и совпадения URL с путями в репозитории;
- проверка всех относительных ссылок и изображений README;
- ручная проверка установки хотя бы одного raw-файла через Tampermonkey;
- визуальная проверка трёх скриншотов;
- проверка чистого состояния Git после коммита.

После этого создаётся публичный репозиторий от аккаунта `wyrtensi`, ветка `main` отправляется на GitHub, а опубликованные ссылки установки проверяются повторно.
